# MIRAAS ROYALE

**Timeless Comfort. Refined Living.**

A responsive luxury furniture landing page for MIRAAS-ROYALE, built with React and Vite. The design follows a modern organic luxury style, with elegant typography and smooth scroll interactions.

## Tech Stack

- React
- Vite
- HTML, CSS and JavaScript

## Run Locally

```bash
npm install
npm run dev
```

Then open the local link shown in the terminal (usually http://localhost:5173).
