# MIRAAS ROYALE

**Timeless Comfort. Refined Living.**

A responsive luxury furniture landing page for MIRAAS ROYALE, built with React, Vite and Tailwind CSS. The design follows a modern organic luxury style, with elegant typography and smooth scrolling.

## Sections

- Header with mobile menu
- Hero
- Featured Collections
- Signature Pieces
- Brand Story
- Craftsmanship
- Lifestyle Inspiration
- Closing call to action
- Footer

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Design

- Fonts: Cormorant Garamond (headings) and DM Sans (body)
- Colours: Deep Burgundy `#542D32`, Rich Mocha `#49332C`, Warm Cream `#EDE3D7`, Antique Bronze `#B18B65`, Soft Ivory `#F9F5EF`

## Run Locally

```bash
npm install
npm run dev
```

Then open the local link shown in the terminal (usually http://localhost:5173).
