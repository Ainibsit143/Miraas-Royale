# MIRAAS ROYALE

**Timeless Comfort. Refined Living.**

**Live Link**  https://miraas-royale.vercel.app/

A responsive luxury furniture landing page for MIRAAS ROYALE, built with React, Vite and Tailwind CSS. The design uses a rich burgundy, mocha and gold palette, with elegant typography, large furniture photography and subtle scroll animations.

## Sections

- Header with a transparent-to-solid scroll effect and a mobile menu
- Hero with a full-width background image
- Featured Collections (Living Room, Bedroom, Dining Room, Accent Furniture)
- Signature Pieces with sample prices in PKR
- Craftsmanship
- Lifestyle inspiration
- Highlights bar
- Closing call to action
- Footer with contact details, social icons and a newsletter box

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- JavaScript

## Design

- Fonts: Cormorant Garamond (headings) and DM Sans (body)
- Colours: Deep Burgundy `#542D32`, Rich Mocha `#49332C`, Warm Cream `#EDE3D7`, Antique Bronze `#B18B65`, Soft Ivory `#F9F5EF`, Gold `#C9A66B`

## Project Structure

```
src/
  components/   Header, Hero, Collections, Signature, Craftsmanship,
                Lifestyle, Features, CTA, Footer, Reveal
  App.jsx
  index.css     Tailwind import and theme colours and fonts
public/
  images/       Photography used across the page
```

## Run Locally

```bash
npm install
npm run dev
```

Then open the local link shown in the terminal (usually http://localhost:5173).

## Build for Production

```bash
npm run build
```

## Notes

- Product names, prices, contact details and social links are placeholders.
- The newsletter box is a front-end demo only and does not send emails.
- Images were generated with AI and are used as placeholders for final photography.
